# Тихая Гавань

Анонимное веб-приложение для поддержки «человек человеку», реализованное по [`prd.md`](../prd.md).

## Как запустить

Никакой установки не требуется — это статичное веб-приложение на HTML/CSS/JS.

1. Открой [`index.html`](index.html) в браузере (двойной клик или перетащить в окно браузера).
2. Готово. Приложение работает полностью локально, в браузере.

Для проверки синхронизации «в реальном времени» открой `index.html` в двух вкладках одного браузера —
новые посты и ответы появятся в обеих вкладках без перезагрузки.

## Что реализовано (MVP из PRD)

- Лента постов, новые сверху, с относительным временем и счётчиком ответов.
- Публикация поста: категория (Работа / Отношения / Семья / Здоровье / Деньги / Другое),
  текст 10–2000 символов, счётчик символов, запрет на ссылки.
- Анонимные ответы (советы) под постом, до 800 символов, в хронологическом порядке.
- Отметка «Стало легче ✓» — доступна любому читателю (в MVP автор технически неотличим от других).
- Мягкий кризисный фильтр по ключевым словам (суицид/самоповреждение) — показывает ненавязчивое
  сообщение с телефоном доверия, не блокируя отправку.
- Светлая/тёмная тема (переключатель + автоопределение системной темы).
- Адаптивная вёрстка под мобильный экран, видимый фокус для клавиатурной навигации.
- Полностью анонимно: нет регистрации, профилей, лайков, подписок; посты и ответы не привязаны
  к автору.

## Важное ограничение текущей версии

Данные хранятся в `localStorage` браузера на этом устройстве — лента **не является общей**
между разными людьми/компьютерами (в отличие от изначального Claude-артефакта, где была общая
лента через служебное хранилище). Это тот же тип ограничения, что описан в PRD (раздел 10,
«Текущий статус»): для настоящего публичного запуска нужен отдельный бэкенд и база данных
(см. PRD, раздел 9 «Риски», строка «Масштабирование хранилища»).

Node.js/Python на машине, где собирался проект, не были установлены, поэтому вместо
серверного стека выбран вариант без сборки и без рантайма — его можно открыть где угодно
прямо сейчас. Когда на машине появится Node.js, следующим шагом стоит вынести хранилище
постов в реальный бэкенд (например, Next.js API routes + база данных с realtime-подпиской),
сохранив текущую разметку и стили.
