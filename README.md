# Тихая Гавань

Анонимное веб-приложение для поддержки «человек человеку», реализованное по [`prd.md`](../prd.md).

## Как запустить

Это статичный фронтенд (HTML/CSS/JS без сборки), подключённый к общей базе данных на
[Supabase](https://supabase.com) — лента и ответы видны всем посетителям сайта в реальном времени.

- Публичная версия: **https://alekenovkanat-code.github.io/tihaya-gavan/**
- Локально: просто открой [`index.html`](index.html) в браузере.

### Настройка бэкенда (нужно один раз для нового Supabase-проекта)

1. Создай проект на [supabase.com/dashboard](https://supabase.com/dashboard).
2. Открой **SQL Editor** и выполни скрипт [`sql/schema.sql`](sql/schema.sql) — он создаёт таблицы
   `posts` и `replies`, политики доступа (RLS) для анонимных читателей/авторов и включает realtime.
3. В **Settings → API Keys** скопируй **Project URL** и **anon public key**.
4. Вставь их в начало [`js/app.js`](js/app.js) в переменные `SUPABASE_URL` и `SUPABASE_ANON_KEY`
   (anon key безопасно хранить в клиентском коде — доступ ограничен политиками RLS в базе).

## Что реализовано (MVP из PRD)

- Общая лента постов (Supabase + realtime) для всех посетителей сайта, новые сверху,
  с относительным временем и счётчиком ответов.
- Публикация поста: категория (Работа / Отношения / Семья / Здоровье / Деньги / Другое),
  текст 10–2000 символов, счётчик символов, запрет на ссылки.
- Анонимные ответы (советы) под постом, до 800 символов, в хронологическом порядке.
- Отметка «Стало легче ✓» — доступна любому читателю (в MVP автор технически неотличим от других).
- Мягкий кризисный фильтр по ключевым словам (суицид/самоповреждение) — показывает ненавязчивое
  сообщение с телефоном доверия, не блокируя отправку.
- Светлая/тёмная тема (переключатель + автоопределение системной темы).
- Адаптивная вёрстка под мобильный экран, видимый фокус для клавиатурной навигации.
- Полностью анонимно: нет регистрации, профилей, лайков, подписок; посты и ответы не привязаны
  к автору.

## Что осталось MVP-ограничением

Модерация контента (ручная/AI, жалобы, бан) не реализована — доступ к записи полностью
анонимный и доверительный, как описано в PRD (раздел 9, «Риски»). Это единственный блокер
перед открытием площадки широкой аудитории без ограничений.

```
├── index.html        # разметка страницы (подключает supabase-js через CDN)

├── sql/schema.sql    # схема базы данных и политики доступа для Supabase
└── README.md
```
